\begin{abstract}
This note explains the chiral line-field experiment in the same order in which the code runs it.  The data are short line segments extracted from images.  Each segment gives a location and an orientation, but not an arrow direction, so angles separated by $\pi$ are treated as the same observation.  We first study the uncleaned and cleaned files, then compare two kinds of models: low-dimensional spiral formulae indexed by an exponent $p$, and non-parametric Gaussian-process/RKHS kernel regressions.  The comparison uses two mathematically different scores: held-out axial RSS, which measures predictive error on unseen folds, and evidence-style scores, which combine fit with a complexity penalty through Gaussian-process marginal likelihood or BIC.
\end{abstract}

\section{What the Data Are}
The experiment reads the files \texttt{data/**/arrow\_segments.mat}.  Each row is a segment with endpoints $(x_{1i},y_{1i})$ and $(x_{2i},y_{2i})$.  The location used for modelling is the midpoint
\begin{equation}
  z_i=(x_i,y_i)=\left(\frac{x_{1i}+x_{2i}}{2},\frac{y_{1i}+y_{2i}}{2}\right).
\end{equation}
The image $y$-axis points downward, so the code flips the vertical coordinate before forming the mathematical angle
\begin{equation}
  \hat\alpha_i=\operatorname{atan2}\{-(y_{2i}-y_{1i}),x_{2i}-x_{1i}\}.
\end{equation}
This is an \emph{axial} observation.  A line segment has no head and no tail, so $\hat\alpha_i$ and $\hat\alpha_i+\pi$ describe the same observed line.  Directional statistics handles this by doubling angles, because $\alpha$ and $\alpha+\pi$ become $2\alpha$ and $2\alpha+2\pi$, which are identical on the circle.  This is the standard axial-data construction described in Mardia and Jupp, \emph{Directional Statistics}, Chapter 1, Section 1.1 \cite{mardia2000}.

The cleaned experiment uses a central circular region of interest.  If \texttt{arrow\_maps.mat} has shape $150\times150$, the centre is $(75,75)$ and the radius is $0.39\cdot150=58.5$.  A segment is retained exactly when
\begin{equation}
  \|z_i-(75,75)\|_2\leq 58.5.
\end{equation}
This rule is not a theorem; it is an experimental preprocessing rule chosen to remove the peripheral line fragments and keep the central circular line field.  Its effect is measured directly: across the 39 datasets, the median retained fraction was $0.992$, the retained fraction ranged from $0.414$ to $1.000$, and the median cleaned sample size was 123 segments.

\section{Data Study: Uncleaned and Cleaned Files}
Let the raw dataset for file $j$ be
\[
  \mathcal D_j^{\mathrm{raw}}
  =
  \{(z_{ij},\hat\alpha_{ij}): i=1,\ldots,n_j^{\mathrm{raw}}\}.
\]
The cleaned dataset is the deterministic subset
\[
  \mathcal D_j^{\mathrm{clean}}
  =
  \{(z_{ij},\hat\alpha_{ij})\in\mathcal D_j^{\mathrm{raw}}:
  \|z_{ij}-c_j\|_2\leq R_j\},
  \qquad
  n_j^{\mathrm{clean}}\leq n_j^{\mathrm{raw}}.
\]
For the available arrow maps, $c_j=(75,75)$ and $R_j=58.5$.  This means the cleaning rule changes only the index set of retained observations; it does not rotate, smooth, or re-estimate any angle.  The raw files contain 5,092 total segments across 39 datasets.  The cleaned files contain 4,721 retained segments, so 371 segments are removed.  On a per-dataset basis, $n_j^{\mathrm{raw}}$ has mean 130.56 and median 128, while $n_j^{\mathrm{clean}}$ has mean 121.05 and median 123.  The median retention ratio $n_j^{\mathrm{clean}}/n_j^{\mathrm{raw}}$ is 0.992, which shows that most datasets are changed lightly, but a few peripheral-heavy files are changed strongly.

\section{The Error for a Line Field}
A signed angular error $\hat\alpha_i-\alpha_i$ would be wrong for these data because it would treat two equivalent line directions, $\alpha$ and $\alpha+\pi$, as different.  The experiment therefore uses the axial residual
\begin{equation}
  \Delta_i^{\mathrm{ax}}(\mathcal M)
  =
  \frac{1}{2}
  \operatorname{atan2}\left(
    \sin\{2[\hat\alpha_i-\hat\alpha_{\mathcal M}(z_i)]\},
    \cos\{2[\hat\alpha_i-\hat\alpha_{\mathcal M}(z_i)]\}
  \right).
  \label{eq:axial-residual}
\end{equation}
The factor of two removes the axial ambiguity, and the final factor of $1/2$ maps the residual back to an angle in $[-\pi/2,\pi/2]$.  A perfect fit has $\Delta_i^{\mathrm{ax}}=0$.  A model that is perpendicular to the observed line has $|\Delta_i^{\mathrm{ax}}|=\pi/2$.

For prediction, the code reports held-out axial RSS,
\begin{equation}
  \operatorname{RSS}_{\mathrm{test}}(\mathcal M)
  =
  \frac{1}{K}\sum_{k=1}^K
  \frac{1}{|I_k|}
  \sum_{i\in I_k}
  \left\{\Delta_i^{\mathrm{ax}}(\mathcal M_{-k})\right\}^2,
  \label{eq:test-rss}
\end{equation}
where $I_k$ is the $k$th fold and $\mathcal M_{-k}$ is fit without that fold.  In the code, $K=\min(10,n)$ and the folds are shuffled with random seed 42.  Cross-validation is used here as an estimate of predictive risk; Arlot and Celisse review this risk-estimation and model-selection interpretation in Sections 1, 4, and 6 of their survey \cite{arlot2010}.

\section{The Parametric Spiral Models}
The parametric family used in the current \texttt{src/cleaned\_linefield\_comparison.py} experiment is a one-angle vector-field basis.  After centering the cleaned coordinates, write
\[
  r_i=\sqrt{x_i^2+y_i^2},
  \qquad
  \theta_i=\operatorname{atan2}(y_i,x_i).
\]
For exponent $p$ and pitch parameter $\gamma$, the implemented vector has radial component $\cos\gamma$ and tangential component $-\sin\gamma\,r_i^p$.  Therefore the predicted line angle is
\begin{equation}
  \hat\alpha_{p,\gamma}(z_i)
  =
  \theta_i+
  \operatorname{atan2}\left(-\sin\gamma\,r_i^p,\cos\gamma\right)
  \quad \mathrm{mod}\ \pi.
  \label{eq:parametric-implemented}
\end{equation}
This formula is the mathematical model being tested.  The fixed families are $p=0$ (logarithmic label), $p=1$ (Archimedean label), and $p=2$ (Fermat label).  The continuous parametric family fits $p\in(-1,3)$.  For fixed $p$, the code searches over $\gamma\in[-\pi,\pi]$ and then refines the best values with L-BFGS-B.  For the continuous family, the code searches a grid over $p$ and $\gamma$ and then optimizes both parameters.

Equation~\eqref{eq:parametric-implemented} is deliberately much smaller than a kernel model.  It asks whether one global spiral exponent and one pitch angle can describe the whole cleaned field.  This is an interpretable hypothesis, but it is also restrictive: if the data contain local bends, local noise, or spatially varying pitch, a single pair $(p,\gamma)$ cannot adapt to them.

\section{The Kernel Models}
The kernel models first convert each observed axial angle to the doubled-angle vector
\begin{equation}
  u_i=(\cos 2\hat\alpha_i,\sin 2\hat\alpha_i)\in\mathbb R^2.
  \label{eq:doubled-embedding}
\end{equation}
This maps each line to a point on the unit circle without distinguishing $\hat\alpha_i$ from $\hat\alpha_i+\pi$.  A Gaussian process is fit independently to the two coordinates of $u_i$ using the same covariance matrix.  If the predicted vector at $z$ is $\hat u(z)=(\hat u_1(z),\hat u_2(z))$, the predicted line angle is
\begin{equation}
  \hat\alpha(z)=\frac{1}{2}\operatorname{atan2}\{\hat u_2(z),\hat u_1(z)\}.
\end{equation}

The three exact kernels in the experiment are
\begin{align}
  K_{\mathrm{RBF}}(z,z';\ell)
  &=
  \exp\!\left[-\frac{\|z-z'\|_2^2}{2\ell^2}\right],
  \label{eq:rbf-kernel}\\
  K_{\mathrm{unif}}(z,z';\ell)
  &=
  \mathbf 1\{\|z-z'\|_2\leq \ell\},
  \label{eq:uniform-kernel}\\
  K_{\mathrm{mult}}(z,z';\ell,\kappa)
  &=
  \exp\!\left[-\frac{\|z-z'\|_2^2}{2\ell^2}\right]\,
  \exp\!\left[\kappa\cos\{\vartheta(z)-\vartheta(z')\}\right],
  \label{eq:multiplicative-kernel}
\end{align}
where $\vartheta(z)=\operatorname{atan2}(y,x)$.  The Gaussian RBF kernel says that nearby points should have similar line directions.  The uniform kernel is a local-neighbourhood baseline.  The multiplicative kernel says that two points are especially related when they are both spatially close and have similar polar angle around the centre.

The length-scale grid is not the old absolute grid $\operatorname{geomspace}(0.2,220,14)$.  It is now dataset-adaptive.  Let
\[
  s_X=\max\{\operatorname{range}(x),\operatorname{range}(y),1\},
  \qquad
  d_{\mathrm{nn}}=\operatorname{median}_i \min_{j\neq i}\|z_i-z_j\|_2.
\]
The code sets
\begin{equation}
  \ell_{\min}=\max\left\{\frac{d_{\mathrm{nn}}}{2},\frac{s_X}{80},10^{-3}\right\},
  \qquad
  \ell_{\max}=\max\left\{1.5s_X,4\ell_{\min}\right\},
  \label{eq:ell-grid}
\end{equation}
and then uses 14 geometrically spaced values
\begin{equation}
  \ell_j=\ell_{\min}
  \left(\frac{\ell_{\max}}{\ell_{\min}}\right)^{j/13},
  \qquad j=0,\ldots,13.
\end{equation}
This is what \texttt{geomspace} means: adjacent candidate values have the same multiplicative ratio, so the sweep covers small, medium, and large spatial scales evenly on a logarithmic scale.  The multiplicative kernel additionally sweeps
\[
  \kappa\in\{0,0.5,1,2,4,8,16\}.
\]
For every kernel candidate, the observation-noise parameter $\sigma_n$ is also swept over eight geometrically spaced values,
\begin{equation}
  \sigma_n\in
  \operatorname{geomspace}(0.05b,0.9b,8),
  \qquad
  b=\max\left\{\frac{\operatorname{sd}(u_1)+\operatorname{sd}(u_2)}{2},0.05\right\}.
  \label{eq:sigma-grid}
\end{equation}
Thus the kernel comparison is not using one fixed noise value across all datasets.

\section{Universality and What It Means Here}
Universality is an approximation property, not a score.  A kernel is universal on a compact domain $X$ when its RKHS is dense in $C(X)$, the continuous real-valued functions on $X$ under the uniform norm.  In plain language: with enough data and the right regularization, functions in the RKHS can approximate any continuous target pattern on that compact domain.

The Gaussian RBF kernel is universal on compact subsets of Euclidean space.  The precise reference is Steinwart \cite{steinwart2001}: Definition 4 introduces universal kernels, Corollaries 10 and 11 give universality conditions using Taylor or Fourier expansions, and Example 1 states the Gaussian RBF case.  This theorem supports the use of the RBF model as a flexible non-parametric family.  It does not say that the RBF will automatically win finite-sample prediction, and it does not remove the need to tune $\ell$ and $\sigma_n$.

The multiplicative kernel in \eqref{eq:multiplicative-kernel} inherits the RBF's spatial flexibility and multiplies it by a von-Mises angular similarity.  The angular factor has the Fourier expansion
\[
  \exp\{\kappa\cos(\vartheta-\vartheta')\}
  =
  I_0(\kappa)+2\sum_{m=1}^{\infty}I_m(\kappa)\cos\{m(\vartheta-\vartheta')\},
\]
where $I_m(\kappa)>0$ for $\kappa>0$.  The positive Fourier coefficients are the mathematical reason this factor can represent smooth angular variation around the centre.  The uniform kernel is different: it is included as a local averaging baseline, not because we rely on a universality theorem for it.

\section{Evidence, Bayes Factors, and BIC}
RSS asks, ``How well did the fitted model predict held-out angles?''  Evidence asks a different question: ``How probable are the observed responses after integrating over the latent function values allowed by the model?''  For a kernel with covariance matrix
\begin{equation}
  C_\theta=K_\theta(X,X)+\sigma_n^2I_n,
\end{equation}
and doubled-angle response matrix $U\in\mathbb R^{n\times2}$, the implemented Gaussian-process log marginal likelihood is
\begin{equation}
  \log p(U\mid X,\theta)
  =
  -\frac{1}{2}\operatorname{tr}(U^\top C_\theta^{-1}U)
  -\log |C_\theta|
  -n\log(2\pi).
  \label{eq:gp-evidence}
\end{equation}
The first term rewards fit.  The log-determinant term penalizes models that spread probability mass too diffusely over many possible response patterns.  This is the Gaussian-process Occam factor.  Rasmussen and Williams derive the one-output version in \emph{Gaussian Processes for Machine Learning}, Chapter 2, Equation (2.30), and Algorithm 2.1 gives the Cholesky implementation used by standard GP code \cite{rasmussen2006}.  Equation~\eqref{eq:gp-evidence} is the two-output independent-coordinate extension of that formula.

For the finite-dimensional parametric models, the experiment uses the BIC approximation
\begin{equation}
  \operatorname{BIC}(\mathcal M)
  =
  k_{\mathcal M}\log n-2\log L(\hat\theta_{\mathcal M}),
  \qquad
  \log p(y\mid \mathcal M)\approx -\frac{1}{2}\operatorname{BIC}(\mathcal M).
  \label{eq:bic}
\end{equation}
Here $k_{\mathcal M}=1$ for fixed $p$ because only $\gamma$ is fit, and $k_{\mathcal M}=2$ for continuous $p$ because both $p$ and $\gamma$ are fit.  Schwarz introduced this large-sample criterion in \emph{The Annals of Statistics}, 6(2):461--464 \cite{schwarz1978}.  Kass and Raftery, Section 3 and their opening summary, explain Bayes factors and note that BIC gives a rough approximation to log Bayes factors \cite{kass1995}.

Across datasets, the total evidence for model $m$ is
\begin{equation}
  E_m^{\mathrm{tot}}=\sum_{j=1}^{39}E_{mj}.
\end{equation}
The Bayes factor comparing model $m$ to the best model $m_\star$ is
\begin{equation}
  \operatorname{BF}_{m,m_\star}
  =
  \exp\{E_m^{\mathrm{tot}}-E_{m_\star}^{\mathrm{tot}}\},
  \qquad
  \log_{10}\operatorname{BF}_{m,m_\star}
  =
  \frac{E_m^{\mathrm{tot}}-E_{m_\star}^{\mathrm{tot}}}{\log 10}.
  \label{eq:bayes-factor}
\end{equation}
This is why the Bayes factor is related to the residual score but is not the same number.  Residuals enter the likelihood term, but the evidence also contains covariance geometry, noise scale, and the log-determinant complexity penalty.

\section{Streamline Diagnostics}
The numerical scores are the primary evidence, but streamline plots help explain what the fitted line fields look like.  A streamline is an integral curve of the fitted orientation field.  If $\hat\alpha(z)$ is the fitted line angle, the displayed curves follow the local direction
\[
  \frac{d z(t)}{dt}
  =
  \{\cos \hat\alpha(z(t)),\sin \hat\alpha(z(t))\},
\]
with the understanding that the opposite sign gives the same line field.  These plots are diagnostic rather than part of the scoring function: the scores come from Equations~\eqref{eq:test-rss} and \eqref{eq:gp-evidence}, while the streamlines translate the fitted angle functions into geometry.

The consulting interpretation is therefore simple but important.  The cleaned central field is not best described by the current one-exponent parametric spiral family.  The parametric models are interpretable and sometimes score well under evidence because they are low-dimensional, but their held-out errors are much larger.  The multiplicative kernel performs best because it has the right kind of flexibility: it is smooth in Euclidean location and also respects polar position around the centre.

\section{What Is Certain, and What Is Not}
The exact data cleaning rule, axial residual, parametric formula, kernels, hyperparameter grids, RSS table, evidence table, and Bayes-factor table are backed by the cleaned-experiment code and its generated CSV files.  The relevant local paths are \path{src/cleaned_linefield_comparison.py} and \path{data/cleaned_linefield_comparison/}.  The citations above back the statistical tools: axial doubling, cross-validation, GP marginal likelihood, BIC, Bayes factors, and RBF universality.

Two points are deliberately stated as limitations rather than conclusions.  First, the ROI cleaning rule is an experimental design choice, not a statistical theorem.  Second, the evidence table mixes exact GP marginal likelihoods for the kernel models with BIC approximations for the parametric models.  That is a useful evidence-style comparison, but it is not the same as a fully Bayesian analysis with matched priors over every kernel and parametric hyperparameter.

\begin{abstract}
This note explains the chiral line-field experiment in the same order in which the analysis now uses it.  The data are unoriented line-field observations, so angles separated by $\pi$ are treated as the same observation.  The Gabor vector-field exports are analysed first because they are the target streamline dataset: each CSV supplies a coordinate and a local pitch angle $\alpha'$, and the non-parametric model is a Nadaraya--Watson kernel smoother for that pitch.  The optical/SEM line-segment measurements are treated as local line-field smoothing problems, not as global GP/RKHS regression problems and not as global parametric spiral fits.  In both settings, held-out axial reconstruction error is used as the main anti-overfitting diagnostic for the local kernel descriptions.
\end{abstract}

\section{What the Gabor Data Are}
The primary streamline experiment uses the Gabor vector-field exports in \path{vf_exports/*_rings_coords.csv}.  Each row contains a spatial coordinate and a local pitch angle $\alpha'$.  The coordinate column is parsed into $z_i=(x_i,y_i)$, the final non-data summary row is dropped, and the pitch angle is converted from degrees to radians.  Because $\alpha'$ is measured relative to the radial coordinate frame, the global field angle is obtained by adding the polar coordinate angle $\operatorname{atan2}(y_i,x_i)$.  The non-parametric model therefore smooths the pitch angle and then reconstructs the displayed streamline direction.

\section{What the Optical Data Are}
The optical reference experiment reads the files \texttt{data/**/arrow\_segments.mat}.  Each row is a segment with endpoints $(x_{1i},y_{1i})$ and $(x_{2i},y_{2i})$.  The location used for modelling is the midpoint
\begin{equation}
  z_i=(x_i,y_i)=\left(\frac{x_{1i}+x_{2i}}{2},\frac{y_{1i}+y_{2i}}{2}\right).
\end{equation}
The image $y$-axis points downward, so the code flips the vertical coordinate before forming the mathematical angle
\begin{equation}
  \hat\alpha_i=\operatorname{atan2}\{-(y_{2i}-y_{1i}),x_{2i}-x_{1i}\}.
\end{equation}
This is an \emph{axial} observation.  A line segment has no head and no tail, so $\hat\alpha_i$ and $\hat\alpha_i+\pi$ describe the same observed line.  Directional statistics handles this by doubling angles, because $\alpha$ and $\alpha+\pi$ become $2\alpha$ and $2\alpha+2\pi$, which are identical on the circle.  This is the standard axial-data construction described in Mardia and Jupp, \emph{Directional Statistics}, Chapter 1, Section 1.1 \cite{mardia2000}.

The cleaned experiment uses a central circular region of interest.  If \texttt{arrow\_maps.mat} has shape $150\times150$, the centre is $(75,75)$ and the radius is $0.39\cdot150=58.5$.  A segment is retained exactly when
\begin{equation}
  \|z_i-(75,75)\|_2\leq 58.5.
\end{equation}
This rule is not a theorem; it is an experimental preprocessing rule chosen to remove the peripheral line fragments and keep the central circular line field.  Its effect is measured directly: across the 39 datasets, the median retained fraction was $0.992$, the retained fraction ranged from $0.414$ to $1.000$, and the median cleaned sample size was 123 segments.

\section{Optical Data Study: Uncleaned and Cleaned Files}

\[

\]
The cleaned dataset is the deterministic subset
\[
  \mathcal D_j^{\mathrm{clean}}
  =
  \{(z_{ij},\hat\alpha_{ij})\in\mathcal D_j^{\mathrm{raw}}:
  \|z_{ij}-c_j\|_2\leq R_j\},

For the available arrow maps, $c_j=(75,75)$ and $R_j=58.5$.  This means the cleaning rule changes only the index set of retained observations; it does not rotate, smooth, or re-estimate any angle.  The raw files contain 5,092 total segments across 39 datasets.  The cleaned files contain 4,721 retained segments, so 371 segments are removed. The median retention ratio $n_j^{\mathrm{clean}}/n_j^{\mathrm{raw}}$ is 0.992, which shows that most datasets are changed lightly, but a few peripheral-heavy files are changed strongly.

\section{The Error for a Line Field}
A signed angular error $\hat\alpha_i-\alpha_i$ would be wrong for these data because it would treat two equivalent line directions, $\alpha$ and $\alpha+\pi$, as different.  The experiment therefore uses the axial residual
\begin{equation}
  \Delta_i^{\mathrm{ax}}(\mathcal M)
  =
  \frac{1}{2}
  \operatorname{atan2}\left(
    \sin\{2[\hat\alpha_i-\hat\alpha_{\mathcal M}(z_i)]\},
    \cos\{2[\hat\alpha_i-\hat\alpha_{\mathcal M}(z_i)]\}
  \right).
  \label{eq:axial-residual}
\end{equation}
The factor of two removes the axial ambiguity, and the final factor of $1/2$ maps the residual back to an angle in $[-\pi/2,\pi/2]$.  A perfect fit has $\Delta_i^{\mathrm{ax}}=0$.  A model that is perpendicular to the observed line has $|\Delta_i^{\mathrm{ax}}|=\pi/2$.

For prediction, the code reports held-out axial RSS,
\begin{equation}
  \operatorname{RSS}_{\mathrm{test}}(\mathcal M)
  =
  \frac{1}{K}\sum_{k=1}^K
  \frac{1}{|I_k|}
  \sum_{i\in I_k}
  \left\{\Delta_i^{\mathrm{ax}}(\mathcal M_{-k})\right\}^2,
  \label{eq:test-rss}
\end{equation}
where $I_k$ is the $k$th fold and $\mathcal M_{-k}$ is fit without that fold.  In the code, $K=\min(10,n)$ and the folds are shuffled with random seed 42.  Cross-validation is used here as an estimate of predictive risk; Arlot and Celisse review this risk-estimation and model-selection interpretation in Sections 1, 4, and 6 of their survey \cite{arlot2010}.

\section{The Parametric Spiral Models}
The parametric baseline is a one-angle vector-field basis.  After centering the cleaned coordinates, write
\[
  r_i=\sqrt{x_i^2+y_i^2},
  \qquad
  \theta_i=\operatorname{atan2}(y_i,x_i).
\]
For exponent $p$ and pitch parameter $\gamma$, the implemented vector has radial component $\cos\gamma$ and tangential component $-\sin\gamma\,r_i^p$.  Therefore the predicted line angle is
\begin{equation}
  \hat\alpha_{p,\gamma}(z_i)
  =
  \theta_i+
  \operatorname{atan2}\left(-\sin\gamma\,r_i^p,\cos\gamma\right)
  \quad \mathrm{mod}\ \pi.
  \label{eq:parametric-implemented}
\end{equation}
This formula is the mathematical model being tested.  The fixed families are $p=0$ (logarithmic label), $p=1$ (Archimedean label), and $p=2$ (Fermat label).  The continuous parametric family fits $p\in(-1,3)$.  For fixed $p$, the code searches over $\gamma\in[-\pi,\pi]$ and then refines the best values with L-BFGS-B.  More exactly, the coarse search uses
\[
  \gamma\in\operatorname{linspace}(-\pi,\pi,361),
\]
keeps the six best grid starts, and runs one-dimensional L-BFGS-B from those starts with bound $[-\pi,\pi]$.  For the continuous family, the code first searches
\[
  p\in\operatorname{linspace}(-0.95,2.95,79),
\]
using the same six-start $\gamma$ fit at each grid value.  It then keeps the eight best $(p,\gamma)$ starts and runs two-dimensional L-BFGS-B with bounds $p\in[-0.999,2.999]$ and $\gamma\in[-\pi,\pi]$.  In cross-validation, the same fitting rule is applied inside each training fold.

Equation~\eqref{eq:parametric-implemented} is deliberately much smaller than a kernel model.  It asks whether one global spiral exponent and one pitch angle can describe the whole cleaned field.  This is an interpretable hypothesis, but it is also restrictive: if the data contain local bends, local noise, or spatially varying pitch, a single pair $(p,\gamma)$ cannot adapt to them.

\section{The Non-Parametric Kernel Smoother}
The non-parametric analysis uses a Nadaraya--Watson kernel smoother, not the Gaussian-process or kernel-ridge posterior mean.  The distinction matters.  A GP/KRR fit has the form
\[
  k_\eta(z,Z)\{K_\eta(Z,Z)+\sigma_n^2I\}^{-1}U,
\]
which solves one global linear system and can transmit influence through the whole dataset.  The smoother used here is instead a normalized local average:
\begin{equation}
  \hat a(z)
  =
  \frac{\sum_{i=1}^n K_\eta(z,z_i)a_i}
       {\sum_{i=1}^n K_\eta(z,z_i)}.
  \label{eq:nw-smoother}
\end{equation}
There is no matrix inverse and no observation-noise parameter $\sigma_n$ in Equation~\eqref{eq:nw-smoother}.  The regularization is controlled by the bandwidth and, for the multiplicative kernel, by the angular concentration $\kappa$.  With a smooth positive kernel such as the Gaussian RBF, the fitted field changes continuously and smoothly with position; with a small bandwidth it remains local, and with a large bandwidth it approaches a global average.

For the optical SEM line fields, the smoother is applied directly to the observed line-angle embedding
\begin{equation}
  u_i=(\cos 2\hat\alpha_i,\sin 2\hat\alpha_i)\in\mathbb R^2,
  \qquad
  \hat u(z)
  =
  \frac{\sum_{i=1}^n K_\eta(z,z_i)u_i}
       {\sum_{i=1}^n K_\eta(z,z_i)}.
  \label{eq:optical-nw-smoother}
\end{equation}
The fitted optical line angle is then
\begin{equation}
  \hat\alpha(z)
  =
  \frac12\operatorname{atan2}\{\hat u_2(z),\hat u_1(z)\}.
  \label{eq:optical-nw-backtransform}
\end{equation}
This is a local estimator of the line field itself.  It is therefore better matched to SEM images where the important structure is a smooth local texture rather than one globally coherent latent function over the whole image.

For the Gabor CSV files, the observed angle column is the local pitch angle $\alpha'_i$, not the global field angle.  The global line-field angle is reconstructed as
\begin{equation}
  \phi_i=\operatorname{atan2}(y_i,x_i)+\alpha'_i.
  \label{eq:gabor-global-angle}
\end{equation}
The smoother is therefore applied to the pitch embedding
\begin{equation}
  a_i=(\cos 2\alpha'_i,\sin 2\alpha'_i)\in\mathbb R^2,
  \label{eq:pitch-doubled-embedding}
\end{equation}
which preserves the axial symmetry of the line field.  After smoothing, the fitted pitch and fitted streamline angle are
\begin{equation}
  \hat\alpha'(z)
  =
  \frac12\operatorname{atan2}\{\hat a_2(z),\hat a_1(z)\},
  \qquad
  \hat\phi(z)=\operatorname{atan2}(y,x)+\hat\alpha'(z).
  \label{eq:nw-backtransform}
\end{equation}
This is the same modelling geometry used by \path{python_notebooks/streamlines.ipynb}: remove the analytic radial rotation, smooth the remaining pitch, and then reconstruct the streamline direction.

The kernels used for the local smoothers are
\begin{align}
  K_{\mathrm{RBF}}(z,z';h)
  &=
  \exp\!\left[-\frac{d(z,z')^2}{2h^2}\right],
  \label{eq:rbf-kernel}\\
  K_{\mathrm{unif}}(z,z';h)
  &=
  \mathbf 1\{d(z,z')\leq h\},
  \label{eq:uniform-kernel}\\
  K_{\mathrm{mult}}(z,z';h,\kappa)
  &=
  \exp\!\left[-\frac{d(z,z')^2}{2h^2}\right]\,
  \exp\!\left[\kappa\cos\{\vartheta-\vartheta'\}\right],
  \label{eq:multiplicative-kernel}
\end{align}
where $\vartheta=\operatorname{atan2}(y,x)$.  For the Gabor pitch smoother, $d(z,z')=|r-r'|$ with $r=\|z\|_2$, so the RBF borrows information across similar radii and the multiplicative RBF--von-Mises smoother additionally requires similar polar angle.  For the optical SEM line fields, $d(z,z')=\|z-z'\|_2$, so the RBF borrows information from nearby image locations, the uniform kernel is a local-neighbourhood average, and the multiplicative kernel further localizes by polar position around the fitted centre.  In all cases, the smoother remains local in the sense needed for streamline fitting: it adapts to local structure without solving a global regression problem.

\section{Universality and What It Means Here}
Universality is an approximation property, not a score.  A kernel is universal on a compact domain $X$ when its RKHS is dense in $C(X)$, the continuous real-valued functions on $X$ under the uniform norm.  In plain language: with enough data and the right regularization, functions in the RKHS can approximate any continuous target pattern on that compact domain.

The Gaussian RBF kernel is universal on compact subsets of Euclidean space.  The precise reference is Steinwart \cite{steinwart2001}: Definition 4 introduces universal kernels, Corollaries 10 and 11 give universality conditions using Taylor or Fourier expansions, and Example 1 states the Gaussian RBF case.  This theorem supports the use of the RBF as a flexible smooth kernel.  It does not say that the RBF will automatically win finite-sample reconstruction, and it does not remove the need to tune the bandwidth.

The multiplicative kernel in \eqref{eq:multiplicative-kernel} inherits the RBF's spatial flexibility and multiplies it by a von-Mises angular similarity.  The angular factor has the Fourier expansion
\[
  \exp\{\kappa\cos(\vartheta-\vartheta')\}
  =
  I_0(\kappa)+2\sum_{m=1}^{\infty}I_m(\kappa)\cos\{m(\vartheta-\vartheta')\},
\]
where $I_m(\kappa)>0$ for $\kappa>0$.  The positive Fourier coefficients are the mathematical reason this factor can represent smooth angular variation around the centre.  In the Gabor pitch-smoothing experiment the multiplicative kernel is a product of radial RBF smoothing and circular von-Mises smoothing; it is used because streamline pitch changes both with radius and with polar location.
\section{Experiment Design}

The experiments use local Nadaraya--Watson kernel smoothers as the main non-parametric descriptions, where the field is reconstructed by averaging nearby observed directions according to a spatial or polar similarity kernel.  For the Gabor streamline data, these smoothers are also compared with low-dimensional parametric spiral baselines, where the entire field is described by one global exponent and one global pitch parameter.  For the optical SEM line fields, the current analysis is restricted to local smoothers because the data are not expected to follow one global spiral law.

We organize the experiments in two stages. s  The Gabor vector-field exports are analyzed first, because they provide pitch-angle measurements on ring-like coordinate clouds and can be directly rerun with the Nadaraya--Watson pitch smoothers.  The optical/SEM line-segment data should then be analyzed with the same local-smoothing philosophy, using Equation~\eqref{eq:optical-nw-smoother} on the doubled-angle line embedding.

\paragraph{Gabor vector-field dataset.}
The Gabor dataset consists of the ten CSV files in \path{vf_exports/*_rings_coords.csv}.
Each row contains a spatial coordinate and a local pitch-angle column
\[
  \texttt{Angle (alpha-prime)}.
\]
The loader parses the coordinate column, removes the non-numeric summary row, converts the pitch angles from degrees to radians, and constructs the corresponding global line-field angle using Equation~\eqref{eq:gabor-global-angle}.

For this dataset, we compare the fixed and continuous parametric spiral families from Equation~\eqref{eq:parametric-implemented} against two Nadaraya--Watson pitch smoothers.  The first is the radial RBF pitch smoother, which uses spatial proximity alone.  The second is the multiplicative RBF--von-Mises pitch smoother from Equations~\eqref{eq:rbf-kernel}--\eqref{eq:multiplicative-kernel}, which combines radial smoothing with angular localization.  The latter is designed for ring-structured fields, where two points may have similar radius but different polar position and therefore should not necessarily be treated as equivalent.

The Gabor kernel sweep is fixed before seeing the test folds.  The bandwidth values are
\[
  h\in\{h_1,\dots,h_{72}\},\quad h_1=1,\ h_{72}=1500,\ \text{and }\frac{h_{j+1}}{h_j}=\text{constant for }j=1,\dots,71,
\]
and the multiplicative smoother additionally searches over
\[
  \kappa\in
  \{0,0.125,0.25,0.5,0.75,1,1.25,1.5,2,3,4,6,8,12,16,24,32,48,64\}.
\]
Every candidate model is scored by shuffled 10-fold held-out axial reconstruction RSS with random seed 42.  This cross-validation criterion is used as an anti-overfitting check: the goal is still to obtain a good streamline description of each field, but the selected smoother must reconstruct held-out orientations rather than merely interpolate all observed directions.

\paragraph{Optical/SEM line-segment dataset.}
The optical dataset consists of 39 cleaned SEM line-field files summarized in \path{data/cleaned_linefield_comparison/}.
Each observation is an image-derived unoriented segment, represented by its midpoint and axial angle.  The preprocessing takes segment midpoints, flips the vertical image axis into mathematical coordinates, and retains the central circular region of interest.

For the optical data, the preferred non-parametric model is the direct line-field Nadaraya--Watson smoother in Equation~\eqref{eq:optical-nw-smoother}.  The RBF smoother uses Euclidean image distance, the uniform smoother uses a finite local neighbourhood, and the multiplicative RBF--von-Mises smoother uses Euclidean image distance times polar-angle similarity about the image centre.  Hyperparameters are selected by spatially blocked held-out axial RSS, not by GP marginal likelihood, because the goal is a smooth local streamline description rather than a globally regularized probabilistic interpolant.

The optical NW sweep uses
\[
  h\in\{h_1,\dots,h_{72}\},\quad h_1=1,\ h_{72}=220,\ \text{and }\frac{h_{j+1}}{h_j}=\text{constant for }j=1,\dots,71,
\]
for the RBF and uniform kernels, and the same bandwidth grid crossed with
\[
  \kappa\in
  \{0,0.125,0.25,0.5,0.75,1,1.25,1.5,2,3,4,6,8,12,16,24,32,48,64\}
\]
for the multiplicative kernel.  The held-out score uses five spatially blocked folds whenever enough spatial blocks are available; otherwise it falls back to shuffled folds.  The raw files used for this rerun are the 39 \path{arrow_segments.mat} files in \path{/Users/rishabhkumar/Downloads/arrow_export_integrated}.  Outputs are written to \path{data/optical_sem_nw_smoother_comparison/}.  The existing files in \path{data/cleaned_linefield_comparison/} are retained only as an archived RKHS/GP reference.

\section{Archived Evidence, Bayes Factors, and BIC}
This section is retained only to document the previous optical RKHS/GP reference run.  It is not the preferred model-selection methodology for the local kernel-smoothing analysis.  For the Nadaraya--Watson smoothers, the primary criterion is held-out axial reconstruction error, because there is no GP covariance inverse or observation-noise parameter in Equation~\eqref{eq:nw-smoother}.

RSS asks, ``How well did the fitted model predict held-out angles?''  Evidence asks a different question: ``How probable are the observed responses after integrating over the latent function values allowed by the model?''  For a kernel with covariance matrix
\begin{equation}
  C_\theta=K_\theta(X,X)+\sigma_n^2I_n,
\end{equation}
and doubled-angle response matrix $U\in\mathbb R^{n\times2}$, the implemented Gaussian-process log marginal likelihood is
\begin{equation}
  \log p(U\mid X,\theta)
  =
  -\frac{1}{2}\operatorname{tr}(U^\top C_\theta^{-1}U)
  -\log |C_\theta|
  -n\log(2\pi).
  \label{eq:gp-evidence}
\end{equation}
The first term rewards fit.  The log-determinant term penalizes models that spread probability mass too diffusely over many possible response patterns.  This is the Gaussian-process Occam factor.  Rasmussen and Williams derive the one-output version in \emph{Gaussian Processes for Machine Learning}, Chapter 2, Equation (2.30), and Algorithm 2.1 gives the Cholesky implementation used by standard GP code \cite{rasmussen2006}.  Equation~\eqref{eq:gp-evidence} is the two-output independent-coordinate extension of that formula.

For the finite-dimensional parametric models, the experiment uses the BIC approximation
\begin{equation}
  \operatorname{BIC}(\mathcal M)
  =
  k_{\mathcal M}\log n-2\log L(\hat\theta_{\mathcal M}),
  \qquad
  \log p(y\mid \mathcal M)\approx -\frac{1}{2}\operatorname{BIC}(\mathcal M).
  \label{eq:bic}
\end{equation}
Here $k_{\mathcal M}=1$ for fixed $p$ because only $\gamma$ is fit, and $k_{\mathcal M}=2$ for continuous $p$ because both $p$ and $\gamma$ are fit.  Schwarz introduced this large-sample criterion in \emph{The Annals of Statistics}, 6(2):461--464 \cite{schwarz1978}.  Kass and Raftery, Section 3 and their opening summary, explain Bayes factors and note that BIC gives a rough approximation to log Bayes factors \cite{kass1995}.

Across datasets, the total evidence for model $m$ is
\begin{equation}
  E_m^{\mathrm{tot}}=\sum_{j=1}^{39}E_{mj}.
\end{equation}
The Bayes factor comparing model $m$ to the best model $m_\star$ is
\begin{equation}
  \operatorname{BF}_{m,m_\star}
  =
  \exp\{E_m^{\mathrm{tot}}-E_{m_\star}^{\mathrm{tot}}\},
  \qquad
  \log_{10}\operatorname{BF}_{m,m_\star}
  =
  \frac{E_m^{\mathrm{tot}}-E_{m_\star}^{\mathrm{tot}}}{\log 10}.
  \label{eq:bayes-factor}
\end{equation}
This is why the Bayes factor is related to the residual score but is not the same number.  Residuals enter the likelihood term, but the evidence also contains covariance geometry, noise scale, and the log-determinant complexity penalty.

\section{Optical Streamline Diagnostics}
The numerical scores are the primary evidence, but streamline plots help explain what the fitted line fields look like.  A streamline is an integral curve of the fitted orientation field.  If $\hat\alpha(z)$ is the fitted line angle, the displayed curves follow the local direction
\[
  \frac{d z(t)}{dt}
  =
  \{\cos \hat\alpha(z(t)),\sin \hat\alpha(z(t))\},
\]
with the understanding that the opposite sign gives the same line field.  These plots are diagnostic rather than part of the scoring function: the final local-smoother scores should come from Equation~\eqref{eq:test-rss}, while the archived GP/RKHS evidence score is defined in Equation~\eqref{eq:gp-evidence}.

\section{What Is Certain, and What Is Not}
The Gabor Nadaraya--Watson pitch-smoothing results are backed by \path{src/vf_exports_pitch_kernel_smoother_comparison.py} and \path{data/vf_exports_pitch_kernel_smoother_comparison/}.  The optical Nadaraya--Watson rerun is backed by \path{src/optical_sem_nw_smoother_comparison.py} and \path{data/optical_sem_nw_smoother_comparison/}.  The archived optical GP/RKHS tables are backed by \path{src/cleaned_linefield_comparison.py} and \path{data/cleaned_linefield_comparison/}, and should be read only as a previous baseline.  The citations above back the statistical tools: axial doubling, Nadaraya--Watson smoothing, cross-validation, GP marginal likelihood, BIC, Bayes factors, and RBF universality.

Two points are deliberately stated as limitations rather than conclusions.  First, the ROI cleaning rule is an experimental design choice, not a statistical theorem.  Second, the archived evidence table mixes exact GP marginal likelihoods for the optical kernel models with BIC approximations for the parametric models; this is no longer the preferred optical selection criterion.
